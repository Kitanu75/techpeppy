| Remote Name | Repository URL | Purpose |
|---|---|---|

Whenever making code changes or pushing updates, **always push to both remotes** so Vercel triggers a new production build:
```bash

```

## 3. Database: MongoDB Atlas

- **Cluster**: `Cluster0` (`cluster0.qoft29w.mongodb.net`)
- **Database Name**: `techpeppy`
- **Driver**: Mongoose (`src/lib/mongodb.ts`)
- **Connection String Pattern**:
  ```env
  MONGODB_URI=mongodb+srv://techpeppy_admin:Techpeppy2026@cluster0.qoft29w.mongodb.net/techpeppy?retryWrites=true&w=majority&appName=Cluster0
  ```
- **Fallback Resilience**: If MongoDB is temporarily unreachable, `src/lib/mongodb.ts` and `src/lib/data/store.ts` fall back to resilient in-memory storage so the app never throws unhandled 500 crashes.

---

## 4. Email Infrastructure: Titan SMTP

- **SMTP Host**: `smtp.titan.email`
- **SMTP Port**: `465` (SSL)
- **Sender / Admin Email**: `admin@techpeppy.com`
- **Functionality**:
  - **User Registration**: `sendWelcomeEmail` in `src/lib/email.ts` sends a welcome email upon sign-up.
  - **Contact & Consulting Inquiries**: `src/app/api/contact/route.ts` forwards form messages from `ContactModal` to `admin@techpeppy.com`.
